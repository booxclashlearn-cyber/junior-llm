Today’s concept is this:

A variable stores a value.

name = "Kondwani"
age = 25

A type describes what kind of value it is.

Common Python types:

str     # text
int     # whole number
float   # decimal number
bool    # True or False
list    # ordered collection
dict    # key-value collection

In problem solving, you use these types to represent information.

For example:

Problem: Store a learner’s progress.

You may need:

name = "Kondwani"              # str
completed_days = 2             # int
daily_hours = 1.5              # float
is_consistent = True           # bool
skills = ["Python", "ML"]      # list
profile = {"name": "Kondwani"} # dict
